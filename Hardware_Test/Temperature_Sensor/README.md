# Wiring DHT11 Temperature & Humidity Sensor

This code gets diretly uploaded to the ESP32 via USB connection and will output what the sensor detects within the serial monitor. Ensure to set the serial monitor baud to 115200. The serial monitor will basically act as like a console log, printing out messages of useful information for you to see that the sensor is working.
